1. Что это такое

AI Planner — это приложение для постановки целей и отслеживания прогресса, где вместо ручного заполнения таблиц и галочек пользователь ведёт короткий дневник. ИИ анализирует записи, сам находит полезные события и обновляет прогресс по целям.

Пример:

Цель: «Накопить 50 000 ₽ за 30 дней».
Пользователь пишет: «Сегодня вкусно пообедал, сделал зарядку, отложил 100 ₽ в копилку, помыл посуду».
ИИ понимает: цель по накоплениям стала ближе на 100 ₽, привычка «зарядка» выполнена, «помыл посуду» — бытовое дело.
Если пользователь пишет: «Пришлось срочно достать 1000 ₽ из копилки», ИИ делает −1000 ₽ к прогрессу.
Главная идея: не заставлять человека вести сложные трекеры, а превратить обычный текст в структурированные данные и прогресс по целям.

2. Проблема, которую решает проект

Обычные To-Do и трекеры привычек:

требуют ручного обновления;
не понимают контекст;
не умеют автоматически пересчитывать финансовые цели;
быстро надоедают, потому что это «ещё одна работа».
AI Planner решает это так:

пользователь просто рассказывает, как прошёл день;
ИИ извлекает события, суммы, действия, привычки;
прогресс по целям обновляется автоматически;
появляется ощущение диалога с личным ассистентом, а не заполнения форм.
3. Пользовательский сценарий

Пользователь создаёт цель: «Накопить 50 000 ₽ за 30 дней».
Каждый вечер пишет в приложении свободный текст:

«Сегодня отложил 100 ₽, сходил на зарядку, потратил 500 ₽ на продукты, помыл посуду».
Запись уходит на сервер.
API сразу отвечает: «Запись принята, анализ запущен».
В фоне Python-сервис вызывает LLM, разбирает текст и возвращает события:

+100 ₽ в копилку;
зарядка — выполнено;
продукты — расход 500 ₽;
помыл посуду — бытовое дело.
Go-бэкенд обновляет прогресс цели в PostgreSQL.
Пользователь получает уведомление: «Анализ готов. Прогресс по цели: 48%. Осталось накопить 26 000 ₽».
В статистике видно динамику, прогноз и историю.
4. Основной функционал

Цели: финансовые, привычки, задачи, произвольные.
Дневник: свободный текст без жёсткой структуры.
AI-анализ: извлечение событий, сумм, действий, категорий.
Автоматическое обновление прогресса: +/− к целям.
История и статистика: графики, тренды, прогнозы.
Уведомления: push / WebSocket / SSE о готовности анализа.
Фоновые задачи: ночной пересчёт статистики, генерация summary дня.
Мониторинг: Grafana, Prometheus, логи.

5. Текущее состояние

Сейчас реализованы регистрация и авторизация пользователей, а также базовая работа с дневниковыми записями:

- `POST /diary-entries` — создать запись (требуется Bearer access token);
- `GET /diary-entries` — получить записи текущего пользователя в порядке от новых к старым (требуется Bearer access token).

Записи сохраняются в PostgreSQL и принадлежат пользователю, который их создал. AI-анализ, цели, очередь фоновой обработки, уведомления и статистика пока являются планируемыми функциями.
