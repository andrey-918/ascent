# План развития AI Planner до портфолио-версии

## Цель проекта

Собрать запускаемое локально приложение, которое демонстрирует полный асинхронный сценарий: пользователь создаёт финансовую цель и дневниковую запись, Go API ставит анализ в Kafka, Python worker извлекает события, а Go сохраняет результат и пересчитывает прогресс. Сервисы покрыты тестами, метрики доступны в Prometheus/Grafana, приложение развёртывается в локальном Kubernetes.

Главный приоритет — законченный и понятный сквозной сценарий, а не широкий набор функций и не production-grade инфраструктура.
